# 🧠 Late Plate AI Models Repository

This repository contains the core AI models used in the [Late Plate](https://github.com/YOUR_ORG) project — a smart cooking assistant app powered by machine learning and deep learning.

Each model is organized into a separate **branch** to keep codebases modular, clean, and easy to navigate.

---

## 🌐 Available Model Branches

| Model | Description | Branch |
|-------|-------------|--------|
| 📝 **Recipe Generator (NLP)** | Fine-tuned GPT-2 and LLaMA 3.2 models that generate recipes based on ingredients. | [`recipe-generation`](https://github.com/Late-Plate/AI-Models/tree/recipe-generation) |
| ⭐ **Recommendation Engine** | Hybrid collaborative + content-based filtering to suggest meals. | [`recommendation-system`](http://github.com/Late-Plate/AI-Models/tree/recipe-recommender) |
| 🍅 **Ingredient Recognition (CV)** | YOLOv11 model trained to detect over 60 food ingredients. | [`ingredient-recognition`](https://github.com/Late-Plate/AI-Models/tree/ingredient-detection) |

---

## 📦 Tech Stack

- **Natural Language Processing:** GPT-2, LLaMA 3.2, Hugging Face Transformers
- **Recommender Systems:** Scikit-learn, Pandas, Matrix Factorization
- **Computer Vision:** YOLOv11, OpenCV, PyTorch
- **Backend Integration:** Flask, REST APIs
